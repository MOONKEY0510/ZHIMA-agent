# ChatFloat 隐私说明

生效版本：v2.0.0

ChatFloat 是一款本地优先（local-first）的桌面 AI 助手。我们对隐私的基本承诺是：**你的对话与凭据默认只保存在你自己的电脑上，应用本身不收集、不上传任何个人数据。**

## 我们存储什么，存在哪里

会话历史（对话标题与消息内容）保存在本机的 SQLite 数据库中，位置为 Windows 应用数据目录下的 `com.chatfloat.desktop/chatfloat.db`。服务商配置（名称、Base URL、模型列表、默认选择）保存在同目录的 `providers.json` 中，该文件不包含任何密钥。界面偏好（主题、失焦隐藏、历史开关）保存在 `settings.json` 中。

**长期记忆**（你在设置中主动保存的个人偏好、背景信息）同样保存在本机 SQLite，并且只在你明确确认后才会写入；密码、密钥等敏感内容会被应用拒绝保存。**会话滚动摘要**用于在长对话中保留早期信息，仅保存在本机。**运行诊断记录（trace）**只保存脱敏的运行状态（模型、状态、错误码、耗时），不包含对话正文、工具结果或密钥。

API Key 存放在 **Windows 凭据管理器**（系统级凭据库，条目名为 `ChatFloat`），不会写入任何配置文件，也不会出现在日志或网络请求之外的任何位置。

## 数据何时离开你的电脑

只有当你主动发送消息时，应用才会向你**自己配置的服务商接口**发起网络请求（OpenAI 兼容的 `/v1/chat/completions` 与 `/v1/models`）。请求中会携带对话上下文、你已启用的长期记忆、会话摘要（如有）以及该服务商的 API Key——这是完成问答所必需的。除此之外，应用没有任何遥测、统计、更新检查或其他后台网络请求。

启用联网搜索或网页读取时，应用会向 DuckDuckGo 或你要求读取的公开网页发起请求。**当你读取了剪贴板、文件、PDF 或屏幕截图等本地敏感内容后，Agent 若再向外部服务发送数据，会再次弹窗征求你的确认。**

请注意：你发送给服务商的内容受该服务商自身隐私政策的约束。选择可信的服务商、避免在提问中输入敏感信息，是你需要自行把握的一环。

## 你的控制权

- 你可以在设置中随时关闭"本地会话历史"，关闭后新的对话只保留在内存中、不落盘。
- 设置"长期记忆"区域可查看、编辑、禁用、删除或清空所有记忆。
- 设置"诊断信息"区域可查看并清空脱敏的运行记录。
- 设置中的"清空全部会话数据"可一键删除所有历史（含摘要与运行记录，不含你保留的长期记忆）。
- 卸载应用时，Windows 的"应用和功能"会移除程序文件；`%APPDATA%` 与 `%LOCALAPPDATA%` 下的 `com.chatfloat.desktop` 目录需要你手动删除（这是有意设计，避免误删用户数据）。

## 安全设计要点

WebView 启用了严格的 CSP，不加载任何远程脚本；Markdown 渲染禁止原始 HTML，防止注入；外部链接一律校验为 http/https 后交给系统浏览器打开；非本机的明文 HTTP 接口会在界面上明确警告；日志不记录 API Key、Authorization 头或完整对话内容。

Agent 工具系统在 Rust 侧统一管控：工具参数在执行前经过 Schema 校验；读取本地数据的工具默认要求确认；上下文包含本地敏感数据时，联网工具需要二次确认；敏感工具（剪贴板、文件、PDF、截图）的结果默认不写入本地历史。网页读取通过独立的 SSRF 防护层（仅公网 80/443、逐跳校验重定向、拒绝私网与环回地址）。
